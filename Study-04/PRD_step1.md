# PRD 1단계: 냉장고 사진 → 재료 인식

> 냉장고 재료 인식 & 레시피 추천 웹 앱 (3단계 중 1단계)
> 관련 문서: [PRD_step2.md](PRD_step2.md) (레시피 생성), [PRD_step3.md](PRD_step3.md) (프로필 & 레시피 저장)

## 1. 목표

사용자가 냉장고 사진을 올리면 AI가 사진 속 **식재료 목록**을 찾아서 보여준다. 이 목록은 2단계에서
레시피를 만들 때 그대로 쓰인다.

## 2. 사용자와 사용 상황

- 사용자: 냉장고에 뭐가 있는지 보고 "이걸로 뭘 해 먹지?"를 고민하는 사람
- 상황: 휴대폰으로 냉장고 안을 찍어 두었거나, PC에 냉장고 사진이 있다
- 실행 환경: Google Colab에서 앱을 실행하고, 브라우저 화면으로 사용한다 (로컬 PC가 없어도 동작해야 함)

## 3. 범위

### 포함
- 사진 1장 업로드 (JPG, PNG, WEBP)
- `stealth/space-bunny-alpha` 모델로 사진 속 식재료 인식
- 인식 결과를 목록으로 표시 (재료 이름, 대략적인 양, 확신 정도)
- 사용자가 인식 결과를 **직접 고칠 수 있는** 입력칸 제공 (빠진 재료 추가, 잘못 본 재료 삭제)

### 제외 (이후 단계 또는 범위 밖)
- 레시피 생성: 2단계
- 로그인, 저장: 3단계
- 사진 여러 장 한 번에 올리기
- 유통기한 인식, 칼로리 계산

## 4. 기술 선택

| 항목 | 선택 | 이유 |

| 웹 화면 | Gradio | 파이썬만으로 웹 화면을 만들 수 있고, Colab 안에서 바로 열린다 (Study-01에서도 사용) |

## 5. 기능 요구사항

### F1. 사진 업로드
- 화면에 사진을 끌어다 놓거나 선택하는 영역이 있다.
- 올린 사진은 미리보기로 보인다.
- JPG, PNG, WEBP 이외의 파일(예: 아이폰 HEIC)은 "JPG나 PNG로 바꿔서 올려주세요" 안내를 띄운다.

### F2. 사진 전처리
- 긴 변이 1024px보다 크면 비율을 유지한 채 1024px로 줄인다 (전송 시간과 비용을 줄이기 위해).
- JPEG로 변환한 뒤 base64로 바꿔 `data:image/jpeg;base64,...` 형식으로 보낸다
  (`api_test.py`의 `make_test_image()`와 같은 방식).

### F3. 재료 인식 요청
- "재료 인식하기" 버튼을 누르면 AI에 요청한다.
- 요청하는 동안 버튼을 비활성화하고 "인식 중..." 상태를 보여준다.
- AI에게는 아래 규칙을 지키도록 요청한다 (프롬프트에 포함):
  - 먹을 수 있는 식재료만 찾는다 (그릇, 용기, 냉장고 부품은 제외)
  - 재료 이름은 한국어 일반 명칭으로 쓴다 (예: "계란" 대신 "달걀"처럼 하나로 통일)
  - 포장 때문에 확실하지 않으면 확신 정도를 `낮음`으로 표시한다
  - **반드시 아래 JSON 형식으로만** 답한다

```json
{
  "ingredients": [
    { "name": "달걀", "amount": "약 6개", "confidence": "높음" },
    { "name": "대파", "amount": "1단", "confidence": "보통" }
  ],
  "note": "아래 칸 반찬통 내용물은 잘 보이지 않음"
}
```

### F4. 결과 표시
- 인식된 재료를 표로 보여준다 (이름 / 양 / 확신 정도).
- 확신 정도가 `낮음`인 재료는 눈에 띄게 표시한다 (예: 흐린 글씨, ❓ 표시).
- `note`가 있으면 표 아래에 보여준다.
- 재료가 하나도 없으면 "재료를 찾지 못했어요. 냉장고 안이 잘 보이게 다시 찍어주세요"를 띄운다.

### F5. 재료 목록 수정
- 인식 결과를 쉼표로 구분한 글자로 입력칸에 채워 둔다 (예: `달걀, 대파, 우유`).
- 사용자가 이 칸을 자유롭게 고칠 수 있다.
- **2단계는 이 입력칸의 내용을 최종 재료 목록으로 사용한다.**

## 6. 오류 처리

| 상황 | 화면에 보여줄 메시지 |
|---|---|
| API 키가 환경 변수에 없음 | "API 키가 없어요. Colab에서 키를 불러오는 셀을 먼저 실행해주세요." |
| 401 (키 오류) | "API 키가 올바르지 않아요." |
| 404 또는 모델 없음 | "모델을 찾을 수 없어요. 모델 이름을 확인해주세요." |
| 429 (요청 너무 많음) | "요청이 많아요. 잠시 후 다시 시도해주세요." |
| 60초 이상 응답 없음 | "응답이 늦어요. 다시 시도해주세요." |
| AI 답이 JSON 형식이 아님 | JSON 부분만 한 번 더 찾아서 읽어보고, 그래도 안 되면 AI 답 원문을 그대로 보여준다 |

- 어떤 오류든 앱이 멈추지 않고 화면에 메시지만 띄운다.
- API 키 값은 화면, 오류 메시지, 로그 어디에도 출력하지 않는다.

## 9. 완료 기준

- [ ] 인식 결과를 입력칸에서 고칠 수 있다.
