# PRD 3단계: 사용자 프로필 & 레시피 저장

> 냉장고 재료 인식 & 레시피 추천 웹 앱 (3단계 중 3단계)
> 관련 문서: [PRD_step1.md](PRD_step1.md) (재료 인식), [PRD_step2.md](PRD_step2.md) (레시피 생성)
> 전제: 2단계가 완료되어 재료 목록 → 레시피 카드 생성까지 동작한다.

## 1. 목표

사용자가 **프로필**을 만들고, 마음에 드는 레시피를 **저장**해서 나중에 다시 볼 수 있게 한다.
프로필에 적은 알레르기나 싫어하는 재료는 레시피 추천에도 반영한다.

## 2. 범위

### 포함
- 프로필 만들기 / 고르기 / 수정하기 (닉네임 기반)
- 프로필 정보: 알레르기, 싫어하는 재료, 식단 유형, 요리 실력, 기본 인분
- 2단계 레시피 생성 시 프로필 정보를 반영
- 레시피 저장, 저장 목록 보기, 상세 보기, 삭제
- Colab 런타임이 다시 시작돼도 데이터가 남도록 Google Drive에 저장

### 제외
- 비밀번호, 회원가입, 로그인 보안 (학습용 앱이라 닉네임만 사용)
- 여러 사람이 동시에 쓰는 상황
- 저장한 레시피 공유, 평점, 댓글

> ⚠️ 닉네임만으로 프로필을 고르기 때문에, 앱을 쓸 수 있는 사람은 누구나 모든 프로필을 볼 수 있다.
> 개인정보(실명, 연락처 등)는 프로필에 넣지 않는다.

## 3. 데이터 설계

### 저장 위치
- 데이터 폴더 경로는 환경 변수 `RECIPE_DATA_DIR`로 정한다. 없으면 `fridge_recipe/data/`를 쓴다.
- **Colab에서는 Google Drive 폴더를 쓴다.** Colab 컴퓨터의 파일은 런타임이 다시 시작되면 사라지기 때문이다.

```python
# Colab 셀: Drive 연결 후 데이터 폴더 지정 (앱 실행 전에 한 번)
from google.colab import drive
drive.mount("/content/drive")
os.environ["RECIPE_DATA_DIR"] = "/content/drive/MyDrive/fridge_recipe_data"
```

- 데이터 폴더(`fridge_recipe/data/`)는 `Study-04/.gitignore`에 추가해서 GitHub에 올라가지 않게 한다.

### 파일 형식
JSON 파일 하나(`profiles.json`)에 모든 프로필과 저장 레시피를 담는다.

```json
{
  "version": 1,
  "profiles": {
    "요리초보": {
      "nickname": "요리초보",
      "allergies": ["땅콩", "새우"],
      "dislikes": ["오이"],
      "diet": "제한 없음",
      "skill": "초보",
      "default_servings": 2,
      "created_at": "2026-09-26T21:00:00",
      "saved_recipes": [
        {
          "id": "c1f9...",
          "saved_at": "2026-09-26T21:10:00",
          "source_ingredients": ["달걀", "대파", "밥"],
          "recipe": { "title": "대파 달걀볶음밥", "...": "2단계 레시피 JSON 그대로" }
        }
      ]
    }
  }
}
```

- `recipe`에는 2단계에서 받은 레시피 JSON 한 개를 **고치지 않고 그대로** 넣는다.
- 저장할 때는 임시 파일에 먼저 쓴 뒤 바꿔치기해서, 저장 도중 끊겨도 기존 데이터가 깨지지 않게 한다.
- 파일이 손상되어 읽을 수 없으면 원본을 `profiles.corrupt-날짜-시간.json`(예: `profiles.corrupt-20260926-210000.json`,
  손상이 여러 번 생겨도 예전 백업을 덮어쓰지 않게)으로 옮겨두고 빈 데이터로 시작하며,
  화면에 "저장 데이터를 읽지 못해 새로 시작했어요"를 띄운다.
- 파일을 읽거나 쓰지 못하면(예: Colab에서 Google Drive 연결이 끊김) 파일은 그대로 두고
  "저장 데이터를 읽거나 쓰지 못했어요. Google Drive 연결이 끊겼을 수 있어요. Colab에서 Drive를 연결하는 셀을 다시
  실행해 보세요. (사진 인식과 레시피 추천은 그대로 쓸 수 있어요)"를 띄운다. 앱은 멈추지 않고 1·2단계는 계속 쓸 수 있다.

## 4. 기능 요구사항

### F1. 프로필 선택 / 만들기
- 화면 맨 위에 "프로필" 영역을 둔다.
  - 기존 프로필 선택 상자(`st.selectbox`)
  - 새 닉네임 입력칸 + "새 프로필 만들기" 버튼 (버튼은 입력칸과 같은 높이에 맞춘다)
  - "프로필은 없어도 돼요. 만들어 두면 알레르기·식단을 반영해서 추천받고, 마음에 드는 레시피를 저장할 수 있어요." 안내
- 닉네임 규칙: 앞뒤 공백 제거, 1~20자, 이미 있는 닉네임이면 "이미 있는 닉네임이에요. 다른 닉네임을 쓰거나, 프로필
  목록에서 골라주세요." 안내. 비어 있으면 "새 닉네임 칸에 닉네임을 먼저 써주세요."
- 프로필을 고르지 않아도 1·2단계(인식, 레시피 생성)는 쓸 수 있다. 저장만 막는다.

### F2. 프로필 정보 입력 / 수정
| 항목 | 형태 | 선택지 / 예시 |
|---|---|---|
| 알레르기 | 쉼표 구분 입력 | 땅콩, 새우 |
| 싫어하는 재료 | 쉼표 구분 입력 | 오이, 가지 |
| 식단 유형 | 선택 | 제한 없음 / 채식 / 비건 / 저탄수화물 |
| 요리 실력 | 선택 | 초보 / 보통 / 능숙 |
| 기본 인분 | 1~4 | 2 |

- "프로필 저장" 버튼으로 저장한다. "프로필을 저장했어요!"는 '프로필 정보 수정' 상자 바로 아래(버튼 가까이)에 띄운다.
- 프로필을 고르면 2단계의 "인분" 기본값이 프로필의 기본 인분으로 바뀐다.

### F3. 레시피 생성에 프로필 반영 (2단계 수정)
- 프로필이 선택되어 있으면 2단계 프롬프트에 아래 내용을 추가한다:
  - 알레르기 재료는 **절대 사용하지 않는다** (부족한 재료에도 넣지 않는다)
  - 싫어하는 재료는 가능하면 쓰지 않는다
  - 식단 유형을 지킨다 (예: 채식이면 고기·생선 제외)
  - 요리 실력이 초보면 난이도를 "쉬움" 위주로, 조리 순서를 더 자세히 쓴다
- 알레르기 재료가 재료 목록(1단계 결과)에 있으면 레시피 생성 전에
  "알레르기 재료(땅콩)가 목록에 있어요. 레시피에서는 빼고 추천할게요"를 띄운다.
- 알레르기 재료가 기본 양념(소금·간장 등, PRD_step2 F2)이면 "집에 있다고 가정"하지 않는다.
  프롬프트의 기본 양념 목록에서 빼고, 부족한 재료에서도 지우지 않아 아래 안전장치에 걸리게 한다.
- 안전장치: AI 답을 받은 뒤 `used_ingredients`, `missing_ingredients`, 제목(`title`)에 알레르기 재료 이름이
  들어 있거나, 조리 순서(`steps`)에 두 글자 이상인 알레르기 재료 이름이 들어 있는 레시피는 화면에 보여주지 않고 버린다.
  ('게'처럼 한 글자는 '잘게', '노릇하게' 같은 말에도 걸리므로 조리 순서에서는 보지 않는다.)

### F4. 레시피 저장
- 2단계 레시피 카드마다 "⭐ 저장" 버튼을 둔다.
- 프로필이 선택되지 않았으면 "저장하려면 맨 위에서 프로필을 선택하거나 새로 만들어주세요. 추천받은 레시피는 그대로
  남아 있어요."를 띄운다.
- 같은 프로필에 제목이 같은 레시피가 이미 있으면 "이미 저장된 레시피예요. 맨 위 '⭐ 내 레시피' 탭에서 볼 수 있어요."를
  띄우고 중복 저장하지 않는다.
- 저장하면 "저장했어요! 맨 위 '⭐ 내 레시피' 탭에서 볼 수 있어요." 알림을 띄운다.

### F5. 저장한 레시피 보기
- "내 레시피" 탭(`st.tabs`)을 둔다.
  - 저장한 레시피 목록: 제목, 저장 날짜, 조리 시간 (최신순)
  - 선택한 프로필은 `st.session_state`에 보관한다
  - 하나를 고르면 2단계와 같은 카드 모양으로 상세 내용을 보여준다
  - "삭제" 버튼 (누르면 "'레시피 제목' 레시피를 정말 삭제할까요? 삭제하면 되돌릴 수 없어요." 확인 후 삭제)
- 저장한 레시피가 없으면 "아직 저장한 레시피가 없어요. '🍳 레시피 추천' 탭에서 레시피를 받은 뒤, 마음에 드는 카드의
  ⭐ 저장 버튼을 눌러보세요." 안내.

## 5. 화면 구성 (3단계 완료 시점)

```
┌─ 프로필: [요리초보 ▼]   새 닉네임 [      ] [만들기]  [프로필 수정] ────────┐
│                                                                       │
│  [ 레시피 추천 ] 탭                     [ 내 레시피 ] 탭                 │
│   ├ 1단계: 사진 업로드 → 재료 인식          ├ 저장 목록                   │
│   ├ 재료 입력칸                            ├ 상세 카드                   │
│   ├ 2단계: 조건 선택 → 레시피 추천          └ 삭제                        │
│   └ 레시피 카드 + [⭐ 저장]                                             │
└───────────────────────────────────────────────────────────────────────┘
```

## 7. 완료 기준

- [ ] 새 프로필을 만들고, 알레르기·식단 정보를 저장할 수 있다.
- [ ] 알레르기에 "달걀"을 넣고 달걀이 있는 재료 목록으로 레시피를 만들면, 달걀이 들어간 레시피가 나오지 않는다.
- [ ] 식단을 "채식"으로 하면 고기·생선이 들어간 레시피가 나오지 않는다.
- [ ] 레시피를 저장하면 "내 레시피" 탭에 나타나고, 상세 내용을 볼 수 있다.
- [ ] 같은 레시피를 두 번 저장하면 중복 저장되지 않는다.
- [ ] 저장한 레시피를 삭제할 수 있다.
- [ ] Colab 런타임을 다시 시작한 뒤(Drive 연결 후) 앱을 다시 켜도 프로필과 저장 레시피가 남아 있다.
- [ ] 프로필을 고르지 않은 상태에서도 재료 인식과 레시피 추천은 동작한다.
