---

이 명령어는 `Study-03/questions.js`에 있는 **문제 은행 자체의 통계**를 보여준다. 실제 플레이
기록(`localStorage`의 `quiz:records`)은 각 플레이어의 브라우저 안에만 있어서 이 명령어가 볼 수
없다 — 그건 `/quiz-leaderboard`가 다룬다.

`Study-03/questions.js`의 `questions` 배열을 읽고 아래를 표로 정리해라.

1. **전체 요약**: 전체 문제 수, `id` 최솟값~최댓값, `id`에 빠진 번호나 중복된 번호가 있는지.
2. **카테고리별 문제 수**: 카테고리(한국사/과학/일반상식/의학)마다 몇 문제인지와 전체 대비
   비율(%).
3. **난이도별 문제 수**: 하/중/상/최상마다 몇 문제인지와 비율(%).
4. **카테고리 x 난이도 표**: 각 칸이 몇 문제인지 보여주는 표. 원래 규칙은 칸마다 10문제이니, 10이
   아닌 칸이 있으면 눈에 띄게 표시해라.
5. **힌트 보유 비율**: `hasHint: true`/`false` 문제 수와 비율을 난이도별로 나눠서 보여줘라.
   원래 규칙은 "최상만 `false`, 나머지는 `true`"이니 이 규칙에서 벗어난 문제가 있으면
   `id`와 함께 표시해라.
6. **정답 위치 분포**: 전체 문제에서 `answerIndex`가 0~3(1번~4번)인 문제가 각각 몇 개/몇 %인지.
   특정 번호가 다른 번호의 2배 이상으로 몰려있으면 "찍기에 유리할 수 있음"이라고 짚어줘라.

마지막에 "총 문제 수, 카테고리별 예상 문제 수(카테고리당 40개)와 실제가 맞는지, 정답 분포 쏠림
여부"를 한 줄로 요약해라. 문제 파일을 고치지는 말고, 표와 요약만 보여줘라.
