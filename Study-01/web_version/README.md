# Handwritten Digit Recognizer (Web Version)

Draw a digit (0-9) in the browser and a neural network trained on MNIST predicts which digit it is.

This folder is set up for deployment to [Hugging Face Spaces](https://huggingface.co/spaces), which reads
the metadata block above to know how to run `app.py`. See `CLAUDE.md` in this folder for the deployment
steps and how this differs from the desktop version in `../desktop_version/`.
