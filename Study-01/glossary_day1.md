## 1. 코딩의 기본 개념

**파이썬 (Python)**
우리가 오늘 쓴 프로그래밍 언어 이름. "코드를 어떤 언어로 적었냐"에서 그 "언어"에 해당함.

**라이브러리 (library) / 패키지**
남이 미리 만들어둔 "기능 모음집". 예: `scikit-learn`(AI 모델 도구), `matplotlib`(그림 그리는 도구).
레고 세트에서 미리 만들어진 부품이라고 생각하면 됨. 우리가 다 처음부터 만들지 않고 가져다 씀.

**`pip install`**
필요한 라이브러리를 컴퓨터에 설치하는 명령어. "이 도구 좀 내려받아줘"라는 뜻.

**`requirements.txt`**
이 프로젝트에 어떤 라이브러리(+버전)가 필요한지 적어둔 "장보기 목록" 파일.
`pip install -r requirements.txt` 한 줄로 목록에 있는 걸 한꺼번에 설치 가능.

## 2. 오늘 만든 AI (인공지능) 관련

**인공신경망 (Neural Network) / MLPClassifier**
사람 뇌의 뉴런 구조를 흉내 낸 AI 모델. 오늘 코드에서 `MLPClassifier`라는, 이미 완성되어 있는
"신경망 제작 틀"을 가져다 옵션(은닉층 크기, 반복 횟수 등)만 설정해서 사용함. 직접 밑바닥부터
수학적으로 구현한 게 아님.

**학습(training) / 훈련(train)**
AI에게 정답이 있는 문제(손글씨 숫자 이미지 + 정답 숫자)를 많이 보여주면서 패턴을 익히게 하는 과정.

**정확도 (Accuracy)**
AI가 시험 문제(한 번도 안 본 데이터)를 몇 % 맞혔는지 나타내는 점수.

**MNIST**
손글씨 숫자(0~9) 이미지 7만 장을 모아둔 유명한 공개 데이터셋 (28x28 픽셀 크기).
AI 공부할 때 거의 항상 등장하는 "국민 연습문제집" 같은 존재.

**sklearn 내장 데이터셋 (load_digits)**
scikit-learn이라는 라이브러리 안에 미리 포함된 작은 손글씨 숫자 데이터 (8x8 픽셀, 1,797장).
MNIST보다 작고, 인터넷 다운로드 없이 바로 쓸 수 있어서 처음에 이걸로 먼저 연습함.

**모델 저장 (`joblib.dump`)**
훈련이 끝난 AI(모델)를 파일로 저장해서, 나중에 다시 훈련시키지 않고도 불러와 재사용할 수 있게
하는 것. `mnist_model.joblib` 파일이 그 결과물.

## 3. 깃(Git) / 깃허브(GitHub) - "저장하고 백업하는 시스템"

**깃 (Git)**
파일이 바뀐 기록(역사)을 남겨주는 시스템. "언제, 무엇을, 왜 바꿨는지" 추적 가능.

**깃허브 (GitHub)**
깃으로 관리하는 프로젝트를 온라인에 보관/공유하는 서비스. 구글 드라이브의 "코드 전용 버전"이라고 생각하면 편함.

**커밋 (commit)**
지금 상태를 하나의 "저장 지점(체크포인트)"으로 기록하는 것. 게임의 "세이브 포인트 만들기"와 비슷함.
아직 온라인에는 안 올라간 상태, 내 컴퓨터(서버) 안에서만 기록됨.

**푸쉬 (push)**
커밋해둔 저장 지점을 깃허브(온라인)에 실제로 업로드하는 것. 이제 서버가 사라져도 안전하게 보관됨.

**브랜치 (branch)**
같은 프로젝트 안에서 "다른 작업 줄기"를 만드는 것. 우리는 `claude/friendly-curie-nz960w`라는
이름의 브랜치에서 작업 중.

**저장소 (repository, repo)**
프로젝트 파일들이 모여있는 "폴더 + 변경 기록"을 통틀어 부르는 말. 우리 프로젝트는
`sejoor12345-commits/VibeCoding` 저장소.

**공개(Public) / 비공개(Private) 저장소**
Public: 누구나 인터넷에서 볼 수 있음 (로그인 없이 접근 가능).
Private: 허락받은 사람만 볼 수 있음.
→ Colab에서 우리 코드를 불러오려면 Public으로 바꿔야 했음 (Colab은 우리 저장소에 대한
별도 로그인 정보가 없어서).

**클론 (`git clone`)**
깃허브에 있는 프로젝트 전체를 다른 컴퓨터로 통째로 복사해오는 명령어.

## 4. Google Colab - "브라우저에서 돌아가는 코딩 노트북"

**Colab**
설치 없이 브라우저에서 파이썬 코드를 실행할 수 있는 구글의 무료 서비스. 사지방처럼 터미널 접근이
제한된 환경에서도 사용 가능 (브라우저만 있으면 됨).

**런타임 (runtime) / 세션 (session)**
Colab이 내 코드를 실행해주는 "임시 컴퓨터"를 말함. 일정 시간 방치하거나 새로고침하면
이 임시 컴퓨터가 초기화되고, 그동안 만든 파일/설정도 사라짐 (그래서 매번 클론부터 다시 해야 함).

**`!` (느낌표로 시작하는 명령어)**
Colab 셀에서 "이건 터미널 명령어야"라고 알려주는 기호. 예: `!git clone ...`, `!pip install ...`

**`%cd`**
"폴더 이동해줘"라는 뜻의 Colab 전용 명령어 (`cd` = change directory).

**`%run 파일이름.py`**
파이썬 파일을 "현재 노트북과 같은 환경 안에서" 실행하는 명령어. 이렇게 실행해야 그림판(Gradio)
같은 화면이 노트북 안에 바로 나타남. (`!python 파일이름.py`로 실행하면 화면에 안 나타날 수 있음.)

## 5. 오늘 만든 그림판 앱 (draw_and_predict.py)

**Gradio**
파이썬 코드만으로 "그림판" 같은 웹 화면(UI)을 간단하게 만들 수 있게 해주는 라이브러리.

**Sketchpad**
Gradio가 제공하는 "마우스로 그림을 그릴 수 있는 캔버스" 부품.

**전처리 (preprocessing)**
AI에게 넣기 전에 데이터를 다듬는 과정. 오늘 예시: 그림을 28x28 크기로 줄이고,
색을 반전시키고(검은 선→흰 선), 숫자를 0~1 사이로 맞춤 (AI가 학습했던 MNIST 형식과 맞추기 위해).
